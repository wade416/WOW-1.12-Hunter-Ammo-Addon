# HunterAmmoHUD — 猎人弹药监控

科技感风格的猎人弹药 HUD（魔兽世界 1.12 经典旧世 / Interface 11200）。

## 功能

- **剩余弹药大数字**：显示当前弹药数（千分位格式），与远程攻击按钮的弹药数一致
- **科技感外观**：
  - 深色半透明面板 + 霓虹青色边框与四角角标
  - 背景科技网格 + 循环扫描线动画
  - 分段式弹药量条（刻度分段）
  - 状态点脉冲、低弹药红色脉冲警示（数字/边框/状态点）
- **消耗速率**：按 30 秒统计窗口计算每秒耗弹（`x.xx/s`）
- **剩余时间预估**：按当前速率预估还能打多久（ETA mm:ss，超过一小时显示 h:mm:ss）
- **堆叠组数**：显示当前弹药类型在背包中的堆叠数量（`x3组`）
- **低弹药预警**：跌破阈值时聊天栏提示 + 提示音（可关）

## 数据来源

- 主数据源：`GetInventoryItemCount('player', 0)`——1.12 客户端自身的弹药槽计数（与远程攻击按钮显示的弹药数相同）
- 兜底：扫描背包中的弹药物品（`equipLoc == INVTYPE_AMMO`，或名称含"箭"/"弹"）
- 弹药类型自动判断：弓/弩 → 箭；枪 → 弹

## 命令

```
/ammo lock         锁定/解锁（锁定后点击穿透，不再挡鼠标）
/ammo warn 200     低弹药阈值（发，0=关闭预警）
/ammo scale 1.2    缩放 0.5~2
/ammo sound        预警音开关
/ammo test         非猎人强制显示（调试）
/ammo reset        重置位置
/弹药              同 /ammo
```

## 说明

- 仅猎人显示（其他职业隐藏；可用 `/ammo test` 强制显示）
- 面板默认在屏幕顶部中央，可拖动，位置自动保存
- 量条比例以"本次登录后见过的最大弹药数"为满值，随消耗下降、补弹回升
- 银行中的弹药不计入；脱离战斗/换武器/拾取/使用弹药时自动刷新

版本 1.0.0 · 适配 Interface 11200
